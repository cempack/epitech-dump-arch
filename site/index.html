Extract a function C-F4

int count_text(char const *str, char separator)
{
    stats_t stats = {0, 0};
    int in_word = 0;
    int i = 0;

    while (str[i] != '\0') {
        if (str[i] != separator && !in_word) {
            stats.words++;
            in_word = 1;
        }
        if (str[i] == separator)
            in_word = 0;
        if (str[i] == '\n')
            stats.lines++;
        i++;
    }
    write(1, &stats, sizeof(stats));
    return stats.words;
}
static void count_words(char const *str, char separator, stats_t *stats)
{
    int in_word = 0;
    int i = 0;

    while (str[i] != '\0') {
        if (str[i] != separator && !in_word) {
            stats->words++;
            in_word = 1;
        }
        if (str[i] == separator)
            in_word = 0;
        if (str[i] == '\n')
            stats->lines++;
        i++;
    }
}

int count_text(char const *str, char separator)
{
    stats_t stats = {0, 0};

    count_words(str, separator, &stats);
    write(1, &stats, sizeof(stats));
    return stats.words;
}

in_word and i move in, stats is passed by pointer because the loop changes it. clangd's own extract only works on C++.

Tests where you write.

<leader>cT builds and runs your Criterion tests. A failed assert opens at its line, and the gutter shows which lines the tests ran, in green, and which they missed, in red.

Your Epitech folder, sorted.

epi clones each project into its module, names it from its subject (myls becomes my_ls) and files the PDFs next to it.

epi
Every project with its git state, bootstrap and subjects. enter goes into it, o opens a subject, p runs the pre-delivery check.
epi new
Lists your Epitech repositories not cloned yet, clones one, files its subjects from ~/Downloads.
epi cd radar
Jumps into a project, a module or a bootstrap (epi cd sudo/b).
epi open sudo kickoff
Opens a subject: main, bootstrap, kick-off, roadmap, bonus…
epi bootstrap
Sets up bootstrap/ and keeps its binaries out of git.
epi allowed --save
Reads the authorized functions from the subject, for epitech-predeliver.
epi search fork
Searches the text of every subject you have.
epi sync
Fetches every repository and shows what's behind or unpushed.
epi doctor
Misplaced projects, unsaved work, clutter, updated subjects waiting in Downloads.

Know before the moulinette.

Two commands for the hour before you push.

epitech-predeliver

Clones what you committed into a temporary folder and checks it the way the moulinette will.

Files you never added, tracked build products, unpushed commits. A fresh make, no relink, clean, fclean and re. Banana on every file. Every function the binary calls, against the subject's list. Tests, with coverage.

Exits 1 when something blocks the delivery, so it fits in a git hook.

epitech-mem

Valgrind's report in plain words: each error, leak and file left open, at the line of your code that caused it, with the line where the block was allocated.

--asan rebuilds with AddressSanitizer instead, which also catches overflows on the stack.

Install.

  1. Run this as your user. It asks for sudo when it needs it.

    $ bash <(curl -fsSL https://raw.githubusercontent.com/cempack/epitech-toolkit/main/install.sh)

  2. Open a new terminal and run epitech-doctor. It compiles a real Criterion test and a CSFML program, and gives the command that fixes anything missing.

  3. That's it. A weekly timer keeps epiclang, Banana, the plugins and the commands current. epitech-upgrade does it now.

Arch Linux (Omarchy, EndeavourOS) and Ubuntu 24.04 or 26.04.
