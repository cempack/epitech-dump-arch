Install

One command.
Then it updates itself.

$ bash <(curl -fsSL https://raw.githubusercontent.com/cempack/epitech-toolkit/main/install.sh)

Then open a new terminal and run epitech-doctor: it compiles a real Criterion test and a CSFML program, and prints the fix for anything missing.
