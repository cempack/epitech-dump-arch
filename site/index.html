Plus a few commands of its own.

epi

Clones each project into the right folder with the right name, and files its subject PDFs next to it.

epitech-predeliver

Clones what you committed and checks it like the moulinette: build, relink, Banana, authorized functions, tests.

cd my_ls && epitech-predeliver

epitech-mem

Valgrind's report in plain words, pointing at the line of your code that caused each leak or invalid read.

epitech-mem ./my_ls -l src

epitech-doctor

Tests that things actually work (a Criterion test compiles, Banana reports, the plugin loads) and gives the command that fixes each problem.

Three things to know.

  1. Install

    Run the command at the top of this page as your user, not root. It asks for sudo when it needs it.

  2. Check

    Open a new terminal and run epitech-doctor. Anything missing comes with its fix.

  3. Forget about it

    A weekly timer keeps epiclang, Banana, the editor plugins and the commands current. epitech-upgrade does it now.

Works on Arch Linux (Omarchy, EndeavourOS) and Ubuntu 24.04 or 26.04.
